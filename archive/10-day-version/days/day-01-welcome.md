## What is Claude Code?

Claude Code is a powerful AI assistant that works directly in your terminal (command line), helping you with your daily work. Think of it as having an expert colleague who:

- Reads and writes files in your projects
- Helps you organize and structure your work
- Creates documentation, diagrams, and reports
- Assists with research synthesis and analysis
- Never forgets project context or details

**Key difference from ChatGPT or Claude on the web**: Claude Code can actually work with your files, not just talk about them. It can read your research notes, create documentation, organize folders, and help with real project work.

## Why Should UX/PM Professionals Care?

### Real Use Cases for Your Work

**1. Design Documentation**
- Automatically format and structure design specs
- Create consistent documentation across projects
- Convert rough notes into polished documents
- Generate tables, lists, and structured content

**2. User Research Synthesis**
- Organize interview notes and findings
- Identify patterns across multiple research sessions
- Create summary reports with themes and insights
- Format data into presentable formats

**3. User Flow & Journey Mapping**
- Create text-based user flows (Mermaid diagrams)
- Document user journeys step-by-step
- Maintain and update flow documentation
- Convert workflows into visual diagrams

**4. Competitive Analysis**
- Structure and organize competitive research
- Create comparison matrices
- Synthesize findings from multiple sources
- Generate reports with consistent formatting

**5. Product Requirements**
- Draft PRDs with proper structure
- Organize features and requirements
- Create user stories and acceptance criteria
- Maintain requirement documentation

**6. Meeting Notes & Follow-ups**
- Convert messy meeting notes into structured docs
- Extract action items and decisions
- Create follow-up documentation
- Maintain project memory

## Real Before & After Examples

### Example 1: Meeting Notes

**Before Claude Code** (30 minutes of manual work):
```
Meeting 12/16 - User Onboarding Review
John (PM), Sarah (UX Designer), Mike (Engineer)

- talked about user onboarding
- john mentioned drop-off at step 3
- desktop 68%, mobile 45%
- sarah said need better tooltips
- ACTION: redesign step 3 - Sarah - due 12/23
- also discussed mobile vs desktop
- mobile has worse completion rate
- follow up 12/23
```

**With Claude Code** (2 minutes):
Ask: "Format these meeting notes with clear sections, extract action items"

```markdown
# Product Team Meeting - User Onboarding Review
Date: December 16, 2024
Attendees: John (PM), Sarah (UX Designer), Mike (Engineer)

## Key Discussion Points

### Onboarding Drop-off Analysis
- **Issue**: Significant user drop-off at Step 3 of onboarding flow
- **Current completion rate**:
  - Desktop: 68%
  - Mobile: 45% (significantly worse)

### Proposed Solutions
- Improve tooltips and contextual help at Step 3
- Investigate mobile-specific UX issues

## Action Items
- [ ] Sarah: Redesign Step 3 with improved tooltips (Due: Dec 23)

## Next Steps
- Follow-up meeting scheduled for Dec 23
- Focus on mobile experience improvements
```

> **Important**: Claude Code formats and structures the information YOU provide - it doesn't attend meetings or add details you didn't give it. You provide the raw notes, it helps you organize them professionally.

## What Claude Code Is NOT

Let's be clear about what Claude Code doesn't do:

- **It's not a design tool** - It won't create Figma designs or mockups
- **It's not a coding tool for UX/PM** - You won't write code (unless you want to!)
- **It's not magic** - It works based on your instructions and project files
- **It's not a replacement for your expertise** - It's an assistant that amplifies your work

## Hands-On Exercise: Your First Claude Code Task

**Time**: 20 minutes

**Objective**: Get comfortable starting Claude Code and giving it a simple task.

**Steps:**

1. **Create a project folder for today's work**
   ```bash
   mkdir ~/workshop-day1
   cd ~/workshop-day1
   ```

2. **Start Claude Code**
   ```bash
   claude
   ```

3. **Give Claude a task**

   Try this prompt:
   ```
   Create a brief project overview document for a mobile app redesign project.
   Include sections for: Project Goals, Target Users, Timeline, and Success Metrics.
   Keep it professional but not too formal.
   ```

4. **Review what Claude creates**
   - Does it look good?
   - Is anything missing?
   - Would you change anything?

5. **Iterate if needed**

   Try asking Claude to:
   ```
   Can you add a section about the project team?
   ```

6. **Exit Claude Code**
   ```
   Type: exit
   ```

**Reflection questions:**
- How does this compare to creating the document manually?
- What surprised you?
- What questions do you have?

**Share your experience** in the workshop chat or during Q&A!

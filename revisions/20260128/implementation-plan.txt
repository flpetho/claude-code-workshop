## Delivery Checklist

### Before Each Session

**15 minutes before:**
- [ ] Open all relevant tabs (docs, examples)
- [ ] Test screen sharing
- [ ] Have visuals ready to present
- [ ] Review session plan
- [ ] Join 5 minutes early

---

### During Each Session

**Time management:**
- Set timer for each segment
- Warn at 5 minutes remaining
- Be OK cutting teaching short if needed
- Prioritize hands-on time

**Engagement:**
- Check chat frequently
- Ask "anyone stuck?" regularly
- Call on quiet people
- Celebrate small wins

**Adaptation:**
- If everyone's stuck, pause and clarify
- If everyone's done early, add challenge
- If timing's off, adjust on the fly
- Take notes for next cohort

---

### After Each Session

**Immediately:**
- [ ] Answer lingering questions in Slack
- [ ] Post session recording (if applicable)
- [ ] Share any additional resources
- [ ] Note what to adjust

**Daily:**
- [ ] Review homework submissions (GitHub)
- [ ] Identify who needs extra help
- [ ] Prep for next day's session

## Success Metrics

### Participation

**Track:**
- Attendance rate (target: 90%+)
- Homework completion (target: 80%+)
- GitHub commits per person (target: 10+)
- Day 5 presentation rate (target: 100%)

---

### Learning Outcomes

**By end of workshop, participants should:**
- [ ] Have working tool on GitHub
- [ ] Deployed to GitHub Pages
- [ ] Created 2+ custom commands
- [ ] Understand git workflow
- [ ] Confident to build independently

**Measure via:**
- Portfolio review (GitHub repos)
- Post-workshop survey
- 1-month follow-up (still using it?)

---

### Satisfaction

**Post-workshop survey questions:**

**1. Overall Experience** (1-5 scale)
- How satisfied are you with this workshop?

**2. Content** (1-5 scale)
- Were the materials clear and helpful?
- Was the pacing appropriate?
- Was hands-on time sufficient?

**3. Confidence** (1-5 scale)
- How confident do you feel using Claude Code now?
- How likely are you to continue building with it?
- How likely to recommend workshop to colleagues?

**4. What Worked**
- What was most valuable?
- What should we keep?

**5. What to Improve**
- What was confusing?
- What should we add?
- What should we remove?

**6. Future Plans**
- What will you build next?
- Would you attend an advanced workshop?

**Target:** 4.5+ overall satisfaction
